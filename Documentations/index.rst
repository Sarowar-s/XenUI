XenonUI Documentation
=====================

Welcome to the **XenonUI Framework Documentation**.

XenonUI is a high-performance, cross-platform C++ UI framework designed for speed,
security, and simplicity. It supports both retained and immediate mode rendering
within the same API — giving developers complete control over performance and design.

- `Windows Documentation <windows.rst>`_
- `Mac Documentation <mac.rst>`_
